
=== NEON RETRO PLAYER ===

Это корневая папка плеера.

[ КАК ЗАПУСТИТЬ ]
1. Если запускаете впервые: откройте файл "1_install.bat" (установит компоненты).
2. Чтобы открыть плеер: откройте файл "2_start.bat".

[ СПИСОК ФАЙЛОВ ]
1_install.bat        - Установка библиотек (Первый запуск)
2_start.bat          - Запуск плеера в браузере (Обычный режим)
3_start_electron.bat - Запуск как настольное приложение (Electron)
4_build_web.bat      - Сборка для веба (в папку dist)
5_build_electron.bat - Сборка .exe файла (в папку dist-electron)
6_clean_build.bat    - Полная переустановка и сборка (если есть ошибки)
7_deploy.bat         - Загрузка на GitHub Pages

[ ВАЖНО ]
Не закрывайте черное окно консоли, пока пользуетесь плеером.
